# 🎬 VideoUpscaler — 4K AI Video Super-Resolution & Restoration

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/arkyu2077/ai-video-upscaler/blob/main/examples/4K_AI_Video_Upscaling_Colab_Tutorial.ipynb)

**[VideoUpscaler](https://videoupscaler.co)** is a cloud-native AI video super-resolution platform and Model Context Protocol (MCP) server that transforms low-resolution 480p/720p videos into sharp **1080p, 2K, or 4K Ultra HD** at up to 60fps.

## ✨ Key Capabilities

- **[4K AI Video Upscaler](https://videoupscaler.co/4k-video-upscaler)**: Multi-frame temporal super-resolution that reconstructs crisp edges, faces, and text without inter-frame flickering.
- **[Batch Video Upscaler](https://videoupscaler.co/batch-video-upscaler)**: Process entire media libraries and multi-clip folders concurrently via web or API.
- **[AI Video Denoising](https://videoupscaler.co/denoise-video)**: Strip out low-light ISO grain and compression artifacts while preserving fine texture.
- **[AI Frame Interpolation](https://videoupscaler.co/frame-interpolation)**: Convert 24fps/30fps footage into smooth 60fps video.
- **[AI Video Stabilization](https://videoupscaler.co/stabilize-video)**: Smooth out shaky handheld, action camera, and drone clips.
- **[Workflow & Agent Integrations](https://videoupscaler.co/integrations)**: Official n8n node (`n8n-nodes-videoupscaler`), MCP server (`videoupscaler-mcp`), CLI/Python SDK (`videoupscaler`), and Go SDK (`videoupscaler-go`).

## 🚀 Quickstart

1. Get your API key from **[videoupscaler.co](https://videoupscaler.co)**.
2. Enter your API key, paste a public video URL, select `1080p`, `2k`, or `4k`, and run the Gradio interface!
3. Read the complete API and workflow recipes at **[videoupscaler.co/docs/workflows](https://videoupscaler.co/docs/workflows)**.
